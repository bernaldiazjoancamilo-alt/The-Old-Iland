# THE OLD ILAND

## Descripción del proyecto

THE OLD ILAND es un pequeño videojuego de supervivencia desarrollado en Java. Este trata sobre un  jugador que ha naufragado en una isla y debe conseguir los recursos necesarios para sobrevivir y encontrar la manera de escapar,
durante la partida tendrá que administrar sus recursos, explorar la isla y tomar decisiones para mantenerse con vida.

## Objetivo del juego

El objetivo principal es sobrevivir en la isla y conseguir los materiales necesarios para construir una balsa que permita escapar, pero para que esto sea posible debe conseguir alimentos y mantenerse hidratado ya que de lo contrario pierde salud y puede llehgar a morir.

Para conseguirlo armar la balsa, el jugador debe reunir:
 5 unidades de madera.
 3 unidades de cuerda.

## Acciones disponibles

El juego cuenta con un menú de 6 opciones:

1. Buscar comida: permite conseguir comida de forma aleatoria.
2. Buscar agua: permite conseguir agua de forma aleatoria.
3. Explorar la isla: permite encontrar madera, cuerda o sufrir daños.
4. Descansar: recupera 30 puntos de energía.
5. Construir una balsa: permite escapar si se tienen los materiales necesarios.
6. Salir del juego: termina la partida.

##  Sistema de recursos

El jugador comienza con los siguientes recursos:

SALUD = 100
ENERGIA = 100 
COMIDA = 2 
AGUA = 2 
MADERA = 0
CUERDA = 0 

La comida y el agua se consumen al finalizar cada turno. Si el jugador no dispone de estos recursos, perderá puntos de salud.

## Tecnologías utilizadas

1- Java.
2- Visual Studio Code.
3- Scanner para introducir datos por teclado.
4- Random para generar resultados aleatorios.
5- Códigos ANSI para mostrar colores en la consola.
6- Git y GitHub para el control de versiones.

## Cómo ejecutar el juego

1- Tener instalado Java JDK.
2- Abrir el proyecto en Visual Studio Code.
3- Abrir la terminal.
5- Compilar el archivo:

en el bash:
javac Oldiland.java


Ejecutar el juego en el bash:

java Oldiland
